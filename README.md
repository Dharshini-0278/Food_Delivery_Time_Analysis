# Food Delivery Time Analysis

## Project Objective
This project analyzes factors affecting food delivery time using Python data analytics techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy
- VS Code
- Jupyter Notebook

## Project Workflow
1. Data Understanding
2. Data Cleaning
3. Missing Value Handling
4. Statistical Analysis
5. Data Visualization
6. Correlation Analysis
7. Outlier Investigation
8. Hypothesis Testing
9. Business Insights

## Key Findings
- Traffic significantly affects delivery time.
- Long distances increase delivery delays.
- Weather conditions impact delivery performance.
- Some deliveries showed extreme delays (outliers).
